2. Cleaning Steps

I first read the text file into Python using “open()” and “read()”. I split the text into lines and used while loops to remove the Project Gutenberg header and footer. I then searched the remaining lines for the six chant headings and recorded their indices. Using these indices, I extracted the text belonging to each chant. I converted the text to lowercase and used “re.split(r”[]+“, …)” to separate it into word tokens. I removed empty strings with a list comprehension and stored each word alongside its chant label in a list of dictionaries. One cleaning decision that I made was to convert all words to lowercase, which makes differently capitalize dforms count as the same word, but also removes distinctions betwene proper names and words that appear at the beginning of a sentence. Fortunatley, proper names are not prominent in the raw text, and this does not affect signifcantly what I will be tracking throughout the project. A more significant step that affects my project is the splitting method, which separates contractions and hyphenated words at punctuation which can affect french words like “l’homme” and “l’adore”, but those words are still easily identifiable and does not effect standalone French pronouns like “Il”, “Tu”, and “Je”.

headings = [
    "CHANT PREMIER",
    "CHANT DEUXIÈME",
    "CHANT TROISIÈME",
    "CHANT QUATRIÈME",
    "CHANT CINQUIÈME",
    "CHANT SIXIÈME"
]

text_lines = raw_text.splitlines()

for line in text_lines:
    if "CHANT" in line.upper():
        print(repr(line))

heading_indices = []

for heading in headings:
    found = False

    for i in range(len(text_lines)):
        if text_lines[i].strip() == heading:
            heading_indices.append(i)
            found = True
            break

    if not found:
        print("Heading not found:", heading)

print("Heading indices:", heading_indices)

rows = []

if len(heading_indices) == len(headings):
    for i in range(len(headings)):
        start = heading_indices[i] + 1

        if i < len(headings) - 1:
            end = heading_indices[i + 1]
        else:
            end = len(text_lines)

        chant_text = "\n".join(text_lines[start:end])

        words = re.split(r"[\W]+", chant_text.lower())

        words = [w for w in words if w != ""]

        for w in words:
            rows.append({"word": w, "chant": headings[i]})
