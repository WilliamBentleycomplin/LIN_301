  • The frst investigation I chose was parts of speech. I wanted to examine the distributon of nouns, verbs, and adjectives in each version of Macbeth. The frequency per 1,000 words is stored in a list of dictionaries and converted into a DataFrame.I used a nested for loop to go through each DatatFrame and part of speech. “(df[”pos”] == pos).sum()” counts the number of words im each part of speech category, which produces boolean values that can be summed and give the number of matches.   • The second investigation I chose was scripts to analyze the writing systems of the texts. English and Finnish use Latin writing systems, while Greek uses the Greek writing system. I used unicodedata to identify the name of the first character of each word, and then extract the script from this name compared with the writing system from the language. I used “script_of()” to take a character as its input and then used “unicodedata.name()” in order to retrieve its unicode name. I used “.split()[0]” to extract the first part of that name which will identify the script. Then each word in each language’s DataFrame was looped through and eachh word has its first character examined to identify the script and then the script is compared with its expected script. I then added the results to two lists. The first list stores the language, word, and the identified script, and the second stores words whose scripts do not match the expected script. The lists were then converted into a DataFrame. The results show that all the English and Finnish words use in the corpus use the Latin script, while almost all of the Greek words use Greek script. The English text contains 17,668 Latin script words, the Finnish text contains 12,113 Latin script words, and the Greek text contains 18,122 Greek script words and one Latin script word. The unexpected Greek word is “eγώ”, which combines a Latin character “e” with the Greek characters “γώ”. I think this is a transciption or typographical error. The results show the three texts are mostly consistent in their use of their writing systems, but since my code only identifies the script of the words first character, I can’t be sure that all of the characters in each word are consistent with the expected script.
def script_of(char):
    return unicodedata.name(char, "UNKNOWN").split()[0]


script_rows =[]
unexpected_rows = []

for language, df, expected in [("english", en, "LATIN"), ("finnish", fi, "LATIN"),("greek", el, "GREEK")]:

    for word in df["word"]:
        script = script_of(word[0])
        script_rows.append({"language": language, "word": word, "script": script})
        if script != expected:
            unexpected_rows.append({"language": language, "word": word, "script": script})

script_words = pd.DataFrame(script_rows)
unexpected_words = pd.DataFrame(unexpected_rows)
script_counts = script_words.groupby(["language", "script"]).size()
